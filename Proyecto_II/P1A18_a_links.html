Explorando la etiqueta <a> en HTML

Una practica basica para comprender la creacion de hipervinculos.

Conceptos Basicos y Atributos

1. ¿Qué es la etiqueta <a>?

La etiqueta <a> (del ingles anchor o ancla) se utiliza para crear enlaces en HTML. Permite conectar la pagina actual con otros sitios web, secciones de la misma pagina o direcciones de correo electrónico.

Estructura basica de un hipervinculo: 

<a href="https://www.ejemplo.com"> Texto del enlace</a>

El atributo href especifica la ruta o direccion URL a la que se dirigira el usuario al hacer clic.

2. Atributos Principales

Principales atributos utilizados en la etiqueta <a>

  • href: Define la direccion URL de destino del enlace.
  • target: Indica donde abrir el contenido (por ejemplo _blank abre una nueva pestaña).
  • title: Proporciona informacion adicional sobre el enlace al posicionar el cursor encima.
  • rel: Establece la relacion con el recurso enlazado (por ejemplo noopener noreferrer) por seguridad al usar _blank.
