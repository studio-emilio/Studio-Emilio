Enlaces Externos

Los enlaces externos permiten dirigir al usuario a sitios fuera de nuestra pagina web. Por ejemplo este enlace te llevara a Youtube, un sitio ideal para consumir tutoriales e informacion multimedia. 

                
                    <a href="http://youtube.com" target="_blank" title="Visitar Youtube en una nueva pestaña" rel="noopener noreferrer">Youtube</a>

Enlace para Enviar Correo

Podemos crear un hipervinculo que ejecute la aplicacion de correo predeterminada del usuario para enviar un mensaje directo, haz clic en el siguiente enlace para redactar un correo a nuestro equipo: Enviar Correo Electronico 

                
                    <a href="mailto:equipo@mundodigital.com" title="Enviar Correo Electronico a equipo@mundodigital.com"> Enviar Correo Electronico</a>

Enlace para Descargar Archivos

Mediante el atributo download, indicamos al navegador que descargue un recurso en lugar de abrirlo directamente. Haz clic para obtener un archivo de prueba: Descargar Guia de Examen 

                
                    <a href="Resource/Mi skibidi.pdf" download="Guia_Examenes.pdf"  title="Descargar documento de estudio">Descargar Guia de Examen</a>

Resumen de la etiqueta <a>

  • href Define la direccion URL, un marcador interno (#id), un archivo o un protocolo (mailto:).
  • target = "_blank" Indica que el recurso se debe abrir en una nueva pestaña.
  • title = "..." Proporciona un texto informativo que aparece al posicionar el cursor sobre el enlace.
  • rel = "noopener noreferrer" Aplica medidas de seguridad y privacidad especiales al usar target="_blank".
  • download: Fuerza la descarga del archivo enlazado y permite renombrarlo opcionalmente.

Experimenta combinando estos atributos en tus propios maquetados web para conectar recursos de forma interactiva y segura.
